# Gamification

Applying game-design elements to non-game contexts (Deterding et al., 2011).

## 1. Beyond points, badges, leaderboards (PBL)
PBL alone is shallow and often backfires. Lasting engagement comes from intrinsic motivation.

**Self-Determination Theory** (Deci & Ryan) — people engage when three needs are met:
- **Autonomy** — meaningful choices, not forced paths.
- **Competence** — clear goals, feedback, visible mastery.
- **Relatedness** — connection, collaboration, shared purpose.

## 2. Octalysis core drives (Yu-kai Chou) — quick reference
Epic meaning, accomplishment, empowerment of creativity, ownership, social influence, scarcity, unpredictability, loss avoidance. The first four are "white hat" (feel good); the last few are "black hat" (urgency, can feel manipulative). Use black-hat drives sparingly and transparently.

## 3. Game elements that transfer well
| Element | Business use |
|---|---|
| Clear goal + progress bar | Onboarding, project completion |
| Immediate feedback | Form validation, task completion animations |
| Levels / progressive disclosure | Feature unlocking as skill grows |
| Challenges / quests | Training modules |
| Scenario play / sandbox | Strategy workshops, what-if planning |
| Turn-taking | Facilitated meetings, retrospectives |
| Narrative framing | Change management, vision communication |

## 4. Ethics precepts
1. Serve the user's goals, not just engagement metrics.
2. No dark patterns: fake scarcity, guilt streaks, hidden costs, endless loops.
3. Make rules transparent; let users opt out of competition.
4. Leaderboards demotivate the bottom half — prefer personal bests, team goals, or tiered brackets.
5. Reward mastery and contribution, not mere time spent.

## 5. Learning loop for this repo
For each game built, note: *what made it fun?* → *which element could transfer to a client tool?* Record answers in the relevant `game-studies/` file.
